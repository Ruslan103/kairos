> *«В древнегреческой философии есть два типа времени: Хронос — монотонное тиканье часов, и **Кайрос** — благоприятный, наполненный смыслом момент для правильного действия.»*

**Kairos** — Android-приложение для стратегического и тактического планирования: **OKR**, **матрица Эйзенхауэра** и **фокус на одной задаче**.

Связывает цели с ежедневными действиями:
- **Доска OKR:** «Сегодня» → «Скоро» → «Постоянно» → «Главная цель».
- **Доска Эйзенхауэра:** четыре квадранта приоритетов дня.
- **Зеркалирование задач:** карточка может жить и в плане, и в матрице.
- **Языки UI:** русский и английский.

## ✨ Возможности

### Планирование (OKR + Эйзенхауэр)
- Доска OKR с хабами от шага к главной цели.
- Доска матрицы: Q1–Q4; кнопки на карточке красят задачу и зеркалят её в матрицу.
- Быстрый переключатель досок под шапкой; счётчики задач.
- Проекты, несколько досок, архив, шаблоны досок.

### Основная доска и основной хаб
- **Основная доска** (`★` в проектах) — стартовая и цель быстрой задачи по умолчанию.
- **Основной хаб** — задаётся в меню «Ещё» на доске; при входе на доску открывается он.
- В «Ещё» — список хабов доски с переходом по тапу.

### Фокус «В работе»
- Кнопка ⚡ на карточке — одна задача в фокусе; остальные приглушены.
- Фокус попадает на виджеты домашнего экрана.

### Карточка задачи и хабы
- На открытом хабе: ⚡ / ✓ и меню ⋮ (комментарии, срок, повтор, матрица, перенос, скрыть, удалить…).
- Соседние хабы — лёгкий preview; полный UI и кнопки — после остановки свайпа (мягкий snap).
- Drag & drop внутри хаба и между хабами; удержание — панель других досок внизу.
- Двойной тап по названию доски — экран проектов.

### Сроки, повтор, напоминания
- Срок через DatePicker; экран календаря (просроченные, бейджи Q).
- Повтор задачи; локальные напоминания о дедлайне (время в Настройках).
- Канал уведомлений Android; действия «Готово» / «На завтра» / «Отмена».

### Виджеты
- **Kairos** — фокус + срочные/сегодняшние задачи + быстрое добавление.
- **Kairos Фокус** — только задача «В работе».
- Добавить: долгий тап по рабочему столу → виджеты → Kairos.

### Статусы, комментарии, контакты
- Категории с цветом; менеджер статусов.
- Комментарии к задачам и к хабам (правила).
- Контакты в проектах (звонок / почта / Telegram).

### Быстрая задача и настройки
- Quick Add с виджета или из приложения; цель (доска/хаб) — в Настройках.
- Тема (система / светлая / тёмная), палитра Q1–Q4, язык, Enter = сохранить задачу.
- Онбординг и краткий гайд по OKR.

### Экспорт / импорт
- JSON / `.kairos`; шаринг в мессенджеры; deep link `kairos://import?data=...`.

## Краткая инструкция

1. Откройте доску OKR или Эйзенхауэра; свайпайте хабы горизонтально.
2. Добавьте задачу; при необходимости задайте срок, квадрант Q1–Q4, категорию.
3. ⚡ — взять в работу (отобразится на виджете).
4. «Ещё» на доске → основной хаб, список хабов, сортировка, просроченные.
5. В проектах отметьте **основную доску**; в Настройках — куда падает быстрая задача и время напоминаний.
6. Добавьте виджет на домашний экран для фокуса и дедлайнов.

## 🏛️ Архитектура

Clean Architecture + SOLID + MVVM:

```
app/src/main/java/com/example/kaizenkanban/
├── data/           # Room, DAO, prefs, repository, transfer (.kairos)
├── domain/         # модели, интерфейсы, use cases
├── reminders/      # дедлайн-алерты, быстрые действия из уведомлений
├── widget/         # App Widget (список + фокус)
└── ui/
    ├── board/      # канбан / хабы
    ├── calendar/
    ├── projects/
    ├── settings/
    ├── onboarding/
    ├── i18n/       # RU / EN строки
    ├── navigation/
    ├── theme/
    └── viewmodel/
```

**БД:** Room, актуальная схема **v16**, миграции `4→16` без wipe. UUID для сущностей.

## 🚀 Сборка

**Требования:** Android Studio (Ladybug+), JDK 17+, эмулятор/устройство API 26+.

```bash
git clone https://github.com/Ruslan103/kairos.git
cd kairos
```

Windows: `.\gradlew.bat assembleDebug`  
macOS / Linux: `./gradlew assembleDebug`

APK: `app/build/outputs/apk/debug/app-debug.apk`

Release (при наличии `keystore.properties`): `.\gradlew.bat assembleRelease`
