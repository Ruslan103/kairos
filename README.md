> *«В древнегреческой философии есть два типа времени: Хронос — монотонное тиканье часов, и **Кайрос** — благоприятный, наполненный смыслом момент для правильного действия.»*

**Kairos** — Android-приложение для стратегического и тактического планирования: **лестница целей**, **матрица Эйзенхауэра**, **Обзор прогресса** и **фокус на одной задаче**.

Связывает цели с ежедневными действиями:
- **Лестница целей:** «На стороне контрагента» → «Сделать» → «Планирую» → «Держу курс» → «Главная цель».
- **Доска Эйзенхауэра:** четыре квадранта приоритетов дня.
- **Зеркалирование задач:** карточка может жить и в плане, и в матрице.
- **Языки UI:** русский и английский.

## ✨ Возможности

### Планирование (лестница целей + Эйзенхауэр)
- Доска «Лестница целей» с хабами от ожидания ответа к главной цели.
- Основной хаб по умолчанию — «Сделать».
- Доска матрицы: Q1–Q4; кнопки на карточке красят задачу и зеркалят её в матрицу.
- Быстрый переключатель досок под шапкой; счётчики задач.
- Проекты, несколько досок, архив, шаблоны досок.

### Обзор
- Вкладки **Цели** и **Период**: картина «Всего» или изменение за день / неделю / …
- Полоски прогресса, движение к цели, вероятность выполнения.
- Архив: очистка и удаление сохраняют статистику в журнале (если нет пометки «Не учитывать»).

### Промпты для ИИ
- Пункт проекта: готовые тексты для ChatGPT / DeepSeek / Claude по выбранной цели.
- Режимы: план шагов, пробелы, 7 дней, упрощение дерева, привычки, ретро, критерии, шансы, вклад шагов 1–5.

### Основная доска и основной хаб
- **Основная доска** (`★` в проектах) — стартовая и цель быстрой задачи по умолчанию.
- **Основной хаб** — задаётся в меню «Ещё» на доске; при входе на доску открывается он.
- В «Ещё» — список хабов доски с переходом по тапу.

### Фокус «В работе»
- Кнопка ⚡ на карточке — одна задача в фокусе; остальные приглушены.
- Фокус попадает на виджеты домашнего экрана.

### Карточка задачи и хабы
- На открытом хабе: ⚡ / ✓ и меню ⋮ (комментарии, срок, связи, фото, критерии, матрица, перенос, скрыть, удалить…).
- Группы задач в хабе (долгое нажатие → выбор → сетка); сброс групп — крестик в заголовке хаба.
- Соседние хабы — лёгкий preview; полный UI и кнопки — после остановки свайпа.
- Drag & drop внутри хаба и между хабами; удержание — панель других досок внизу.
- Двойной тап по названию доски — экран проектов; длинные названия — бегущая строка у остановленного хаба.

### Регулярные задачи
- Шаблоны привычек на уровне проекта; экземпляры появляются в выбранном хабе.
- Ритмы: каждый день, по дням недели, каждые N дней.

### Сроки, напоминания
- Срок через DatePicker; экран календаря (просроченные, бейджи Q).
- Локальные напоминания о дедлайне (время в Настройках).
- Канал уведомлений Android; действия «Готово» / «На завтра» / «Отмена».

### Виджеты
- **Kairos** — задача «В работе»; без фокуса — крупные кнопки добавить задачу и голос.
- Добавить: долгий тап по рабочему столу → виджеты → Kairos.

### Статусы, комментарии, контакты
- Категории с цветом; менеджер статусов.
- Комментарии к задачам и к хабам (правила).
- Контакты в проектах (звонок / почта / Telegram).

### Быстрая задача и настройки
- Quick Add с виджета или из приложения; цель (доска/хаб) — в Настройках.
- Тема (система / светлая / тёмная), палитра Q1–Q4, язык, Enter = сохранить задачу.
- Онбординг, гайд по планированию и инструкция «Нажатия и жесты».

### Экспорт / импорт
- JSON / `.kairos`; шаринг в мессенджеры; deep link `kairos://import?data=...`.

## Краткая инструкция

1. Откройте «Лестницу целей» или Эйзенхауэра; свайпайте хабы горизонтально.
2. Добавьте задачу; при необходимости задайте срок, квадрант Q1–Q4, категорию.
3. ⚡ — взять в работу (отобразится на виджете).
4. «Ещё» на доске → основной хаб, список хабов, сортировка, просроченные.
5. В проектах отметьте **основную доску**; в Настройках — куда падает быстрая задача и время напоминаний.
6. Откройте **Обзор** проекта, чтобы увидеть прогресс целей и периоды.
7. Добавьте виджет на домашний экран для фокуса или быстрой задачи / голоса.

## 🏛️ Архитектура

Clean Architecture + SOLID + MVVM:

```
app/src/main/java/com/example/kaizenkanban/
├── data/           # Room, DAO, prefs, repository, transfer (.kairos)
├── domain/         # модели, stats, use cases
├── reminders/      # дедлайн-алерты, регулярные экземпляры
├── voice/          # распознавание и команды
├── widget/         # виджет фокуса (+ быстрая задача / голос)
├── pro/            # заглушка entitlements
└── ui/
    ├── board/      # канбан / хабы
    ├── calendar/
    ├── projects/
    ├── stats/      # Обзор
    ├── recurring/
    ├── eisenhower/
    ├── settings/
    ├── onboarding/
    ├── voice/
    ├── i18n/       # RU / EN строки
    ├── navigation/
    ├── theme/
    └── viewmodel/
```

**БД:** Room, актуальная схема **v29**, миграции без wipe. UUID для сущностей.

## 🚀 Сборка

**Требования:** Android Studio (Ladybug+), JDK 17+, эмулятор/устройство API 26+.

```bash
git clone https://github.com/Ruslan103/kairos.git
cd kairos
```

Windows: `.\gradlew.bat assembleDebug`  
macOS / Linux: `./gradlew assembleDebug`

APK: `app/build/outputs/apk/debug/app-debug.apk`

Release (при наличии `keystore.properties`): `.\gradlew.bat assembleRelease`
