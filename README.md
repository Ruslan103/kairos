> *«В древнегреческой философии есть два типа времени: Хронос — монотонное тиканье часов, и **Кайрос** — благоприятный, наполненный смыслом момент для правильного действия.»*

**Kairos** — современное Android-приложение для стратегического и тактического планирования жизни на базе связки методологий **OKR**, **Матрицы Эйзенхауэра** и **Чанкинга/Фокуса**.

Приложение органично связывает стратегические цели с ежедневными действиями:
- **Доска OKR:** «Сегодня» → «Скоро» → «Постоянно» → «Главная цель».
- **Доска Матрицы Эйзенхауэра:** 4 квадранта («Срочно и важно», «Важно, не срочно», «Срочно, не важно», «Не срочно и не важно»).
- **Зеркалирование задач в 1 клик:** карточки живут одновременно в плане и в матрице приоритетов дня.
- **Быстрый переключатель досок:** мгновенный переход между OKR и матрицей в один тап прямо вверху экрана.

## ✨ Ключевые возможности

### 1. Двухуровневое планирование (OKR + Матрица Эйзенхауэра)
- **Доска OKR (от шага к главной цели):**
  - *Сегодня* — конкретный шаг на этот день
  - *Скоро* — ближайшие дни / неделя
  - *Постоянно* — привычки и практики, которые держите
  - *Главная цель* — большая картина, зачем всё это
- **Доска Эйзенхауэра (дневной фильтр приоритетов):**
  - *Срочно и важно (Q1)* — дедлайны и кризисы
  - *Важно, не срочно (Q2)* — стратегическое развитие и здоровье (ключевой фокус)
  - *Срочно, не важно (Q3)* — рутина и делегирование
  - *Не срочно и не важно (Q4)* — отсечение пожирателей времени
- **Мгновенный свитчер досок в 1 тап** прямо под шапкой с динамическими счетчиками задач.

### 2. Зеркалирование задач между досками в 1 тап
- На каждой карточке есть 1-тап селектор квадрантов: `[ Q1 ]` `[ Q2 ]` `[ Q3 ]` `[ Q4 ]`.
- Нажатие на квадрант мгновенно отправляет задачу на доску Эйзенхауэра, сохраняя её в плане OKR.
- Синхронное обновление: статус «Выполнено», комментарии и сроки синхронизируются в реальном времени.
- Карточки в матрице наглядно показывают свой исходный хаб (*«Из плана: Сегодня»*).

### 3. Режим фокусировки «В работе»
- Выделение текущей задачи ярким неоново-синим и фиолетовым градиентом с бейджем «СЕЙЧАС В РАБОТЕ».
- Плавное затемнение (прозрачность) всех остальных задач для максимального погружения в поток.

### 4. 👆 Продвинутый Drag & Drop и Swipe-to-Reveal
- **Двойной тап по названию доски** открывает экран всех проектов.
- **Swipe-to-Reveal (свайп влево):**
  - **Для задач:** скрывает лишние кнопки с карточки; при свайпе влево выдвигаются действия: 💬 Комментарии, ✏️ Редактировать, 🗑️ Удалить.
  - **Для хабов:** при свайпе заголовка влево открываются кнопки: ✏️ Переименовать и 🗑️ Удалить.
- **Компактная навигация:** быстрые кнопки смены хаба под задачей `[ ◀ ] [ 📁 ] [ ▶ ]` без громоздкого текста, никогда не выходят за экран.
- **Интуитивный Drag & Drop:** перемещение карточек внутри хаба и между соседними хабами с расчетом координат вставки.
- **Междосочное перетаскивание:** при удержании задачи внизу экрана появляется интерактивная панель других досок.

### 5. 🏷️ Управление статусами и категориями
- Цветовое кодирование задач (Размышление, Изучение, Контроль, Исполнение).
- Если статус не выбран — пустые плашки скрываются.
- Полноценный менеджер статусов: создание категорий, редактирование названий и выбор цветовых палитр.

### 6. 💬 Комментарии к задачам
- Добавление заметок, промежуточных результатов и обсуждений к любой задаче.
- Отображение даты и времени каждого комментария со счетчиком на карточке.

### 7. ✅ Секция «Выполнено» и фиксация результата
- Завершение задачи в один клик с красивой анимацией перечеркивания.
- Удобная увеличенная кнопка «Выполнено» в нижней зоне досягаемости большого пальца.
- Завершенные задачи автоматически перемещаются в нижнюю сворачиваемую секцию хаба с отметкой точного времени.

### 8. 📆 Календарь и дедлайны
- Установка сроков выполнения через Material 3 DatePicker.
- Отдельный экран календаря: сортировка по датам, подсветка просроченных задач и бейджи квадрантов Эйзенхауэра.

### 9. 🚀 Экспорт, импорт и шеринг в мессенджеры (Deep Links)
- **Выгрузка и загрузка файлов:** полный экспорт/импорт проектов, досок, хабов, задач и комментариев в формате JSON / `.kairos`.
- **Отправка в мессенджеры (Telegram, WhatsApp, Viber и др.):** формирование превью задач со встроенной кликабельной ссылкой `kairos://import?data=...` и файлом бэкапа.
- **Импорт в 1 клик:** при нажатии на ссылку в мессенджере или клике по файлу `.kairos` приложение мгновенно открывается и загружает все переданные задачи.

## 🏛️ Архитектура и Clean Code

Проект строго следует принципам **Clean Architecture** и **SOLID**:

```
app/src/main/java/com/example/kaizenkanban/
├── data/                  # Слой данных (Data Layer)
│   ├── local/             # Room Database, DAO, Entity, Migrations
│   ├── mapper/            # Мапперы между Entity и Domain-моделями
│   ├── repository/        # Реализация репозиториев (DIP)
│   └── transfer/          # JSON-сериализатор, GZIP, Base64 и Deep Link хелперы
├── domain/                # Бизнес-логика (Domain Layer, чистый Kotlin)
│   ├── model/             # Неизменяемые Domain-модели (Models.kt, TransferData)
│   ├── repository/        # Интерфейсы репозиториев
│   └── usecase/           # Гранулярные Use Cases (ExportData, ImportData и др.)
└── ui/                    # Слой представления (UI Layer)
    ├── board/             # Экран Канбан-доски (BoardScreen)
    ├── calendar/          # Экран календаря (CalendarScreen)
    ├── navigation/        # Навигационный граф (Jetpack Navigation)
    ├── projects/          # Экран управления проектами (ProjectsScreen)
    ├── theme/             # Material 3 темы, палитры и градиенты
    └── viewmodel/         # SharedViewModel, AppState, ViewModelFactory
```

### Применение SOLID:
- **S (Single Responsibility):** каждая операция вынесена в отдельный Use Case (`AddTaskUseCase`, `MoveTaskUseCase`, `MoveTaskToBoardUseCase`, `AddCommentUseCase`, `SetDefaultBoardUseCase` и др.).
- **O (Open/Closed):** интерфейс `KanbanRepository` абстрагирует источник данных и открыт для расширения (например, подключение Firebase / REST API).
- **L (Liskov Substitution):** репозитории и мапперы строго соблюдают контракты интерфейсов.
- **I (Interface Segregation):** независимые контракты сущностей и раздельные методы взаимодействия.
- **D (Dependency Inversion):** Domain-слой не зависит от Android-библиотек или Room; зависимости инжектируются через абстракции.

### База данных и миграции:
- Полноценная поддержка **миграций Room** (`MIGRATION_4_5`, `MIGRATION_5_6`) без удаления пользовательских данных при добавлении новых полей и таблиц.
- Использование UUID для первичных ключей, что упрощает будущую облачную синхронизацию (Firestore / CouchDB).

## 🛠️ Стек технологий

- **Язык:** Kotlin 2.1.0

## 🚀 Установка и запуск

### Требования:
- Android Studio Ladybug / Jellyfish (или новее)
- JDK 17+ (рекомендуется JDK 17 или 21)
- Устройство или эмулятор с Android 8.0+ (API level 26+)

### Сборка из исходников:

1. Клонируйте репозиторий:
   ```bash
   git clone https://github.com/Ruslan103/kairos.git
   cd kairos
   ```

2. Откройте проект в Android Studio или соберите Debug APK через терминал:
   - **Windows:**
     ```cmd
     .\gradlew.bat assembleDebug
     ```
   - **macOS / Linux:**
     ```bash
     ./gradlew assembleDebug
     ```

3. Готовый APK-файл появится по пути:
   `app/build/outputs/apk/debug/app-debug.apk`
